Important: update the screen first. Screens on update 42 or older can restart during an update. If it restarts, just try again (it is safe: nothing changes until an update finishes). Update the screen first, then send the box files. Or update the rear box straight from the phone app (see "Rear box with no screen" below).
Where the files go. iPhone: if a message asks, tap Download. Files are saved in the Files app under Downloads. Android: they're saved in Downloads. Don't rename them. A file only fits the part it was made for, and a wrong one is refused with nothing changed.

2. Put them on your system

  1. Park the vehicle with the power on. Keep your phone within a few feet of the screen.
  2. On the screen, go to Controls, scroll down to SOFTWARE and tap Update software (phone).
  3. Turn your phone's cellular data off for the update.
  4. On your phone, scan the QR code on the screen, or go to WiFi settings and join the QuickLight-XXXX WiFi with the password shown. If it says "No internet", choose Stay connected. If a small sign-in window pops up by itself, close it.
  5. Open Safari or Chrome yourself and go to 192.168.4.1 (don't use the pop-up window).
  6. Tap Choose file, pick ONE file and tap Update. Wait until it says Done.
  7. Tap Close on the screen. For the next file, tap Update software (phone) again and repeat steps 3 to 5.
  8. When you're done, put your phone's WiFi back to normal.
Do them in this order: screen first, then the rear box, then the start box and relay boxes. The screen passes box files on to the box by itself.
Start box: turn the ignition OFF before sending its file, or it won't update. If the screen then shows PIN MUST BE CHANGED, set a new 6-digit master PIN and a 4-digit PIN. Write the master PIN down. A lost PIN can't be recovered.

Rear box with no screen

  1. Download the rear box file above.
  2. Open the Quick Light phone app, tap Connect, scroll down to Software update and tap Update rear box software.
  3. Join the WiFi QuickLight-Rear-XXXX with the password ql268533
  4. Open the browser, go to 192.168.4.1, choose the file and tap Update.
Safe by design. The new program goes into a spare slot. If the power cuts out or something goes wrong, the old program keeps running, so just try again. Brake lights, turn signals and whips keep working during an update.
